# Episode 2 Practice: Installing Python and Setting Up VS Code

Verify your install, run hello.py ideas, and redo the savings challenge with only print and variables.

Practice notebook for the **BuildForward** Python series, episode 2.

- **[Download `episode_02_practice.ipynb`](https://github.com/madaswath/buildforward-python/releases/download/ep02-v1.0/episode_02_practice.ipynb)** (saves the file to your computer)
- **[Open in Google Colab](https://colab.research.google.com/github/madaswath/buildforward-python/blob/main/episode_02/episode_02_practice.ipynb)** (nothing to install, runs in your browser)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/madaswath/buildforward-python/blob/main/episode_02/episode_02_practice.ipynb)

## How to use it

1. Open the notebook in Colab, or in Jupyter if you already have Python installed.
2. Run the first cell once. It adds a small `check` helper.
3. Run each cell with **Shift + Enter**.
4. In an exercise, write your answer in the starter cell, then run the check cell below it.
5. Stuck? Open the **Hint**. Still stuck? Open the **Solution**, read it, then try again from memory.

## Run it on your own computer

```bash
pip install notebook
jupyter notebook episode_02_practice.ipynb
```
